# Blog (Quarto)

Preview locally: `quarto preview` in this folder (needs Quarto, https://quarto.org, and the repo's `.venv`).
Publish: `quarto publish gh-pages` — builds the site and pushes it to the `gh-pages` branch;
it appears at https://jtompuri.github.io/data-science-mini-project/ in about a minute.
Do not publish before the team has approved the content: the site is public.
